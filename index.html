n8n Webhook Configuration & GitHub Pages Guide

1. Configuring the n8n Webhook Node

In your n8n workflow, add a Webhook trigger node with these settings:

  • HTTP Method: POST
  • Path: e.g. cv-upload
  • Respond: Choose "Using 'Respond to Webhook' Node" (or "When Last Node Finishes") so n8n confirms when CV processing has actually finished.
  • Binary Property: The browser sends multipart/form-data with binary field name file alongside metadata fields (cvId, filename, fileSize, mimeType, uploadTimestamp, batchId).

2. Enabling CORS for GitHub Pages Static Hosting

In your n8n Webhook node under Options → Allowed Origins (CORS), set your GitHub Pages domain (e.g. https://your-username.github.io) or *.

3. Returning Explicit Workflow Completion JSON

Because an HTTP 200 alone only means the webhook received the file (Sent to n8n), add a Respond to Webhook node at the end of your n8n workflow returning: 

{
  "status": "completed",
  "cvId": "{{ $json.body.cvId }}",
  "executionId": "{{ $execution.id }}",
  "storageConfirmed": true,
  "storageUrl": "https://drive.google.com/...",
  "message": "CV parsed and stored in candidate database"
}
